# Дәптер — правила проекта

- ТЗ проекта: SPEC.md. Перед любой задачей сверяйся с ним.
- Стек: чистые HTML/CSS/JS (ES-модули), IndexedDB, без фреймворков, без сборки, без CDN.
- Никаких сетевых запросов с данными покупателей.
- Расчёты только в js/ledger.js; любое изменение логики — с тестом в tests/.
- Деньги — целые числа в тенге.
- Все тексты интерфейса — через i18n/ru.json и i18n/kk.json.
- После изменений запускай node --test и сообщай результат.
- Не трогай файлы вне задачи. Не правь SPEC.md без моего разрешения.
- Объясняй по-русски, простыми словами.
